# Фаза 1: Фундамент и Инфраструктура (Спринт 1)

## Общие задачи (FastAPI):
* Создание репозиториев (рекомендуется разделить Frontend, Mobile и Backend, либо использовать Monorepo для удобства).
* Настройка `docker-compose.yml` для локальной разработки (PostgreSQL, Redis, FastAPI).
* Инициализация проекта FastAPI, утверждение базовой структуры (`api/`, `models/`, `core/`, `services/`).

## Задачи по ролям:
* **Никита (AI/ML & FastAPI):** Проектирование схемы БД (ER-диаграмма) для пользователей, расписаний и логов AI. Настройка подключения к PostgreSQL (SQLAlchemy или Tortoise ORM). Настройка Alembic для миграций. Создание тестовых Python-скриптов для интеграции с Groq (Whisper) и Anthropic (Claude).
* **Вадим (Next.js & FastAPI):** Инициализация чистого Next.js 14. Настройка `next.config.js` (`output: 'export'`) для строгой статики. Установка Tailwind CSS, настройка роутинга и базовых layout-компонентов. Создание первого REST-эндпоинта на FastAPI (например, `/api/healthcheck`).
* **Алесь (Flutter & FastAPI):** Инициализация Flutter-проекта. Выбор стейт-менеджмента (рекомендуется Riverpod или BLoC). Настройка базовой архитектуры мобильного приложения. Реализация базового WebSocket-менеджера на FastAPI для тестирования подключения.

# Фаза 2: Аутентификация и Базовый CRUD (Спринт 2)

## Общие задачи (FastAPI):
* Реализация JWT-авторизации (access/refresh токены).
* Создание базовых моделей User и Session.

## Задачи по ролям:
* **Вадим:**
  * **FastAPI:** Написание REST-эндпоинтов регистрации, логина и профиля (`/api/auth/register`, `/api/auth/login`, `/api/users/me`).
  * **Next.js:** Верстка форм авторизации. Настройка Axios-инстанса с перехватчиками (interceptors) для инъекции JWT и логики автоматического рефреша токена.
* **Алесь:**
  * **FastAPI:** Создание эндпоинтов управления друзьями (`/api/friends` - запрос, подтверждение, удаление).
  * **Flutter:** Верстка экранов входа, регистрации и списка друзей. Настройка безопасного хранилища (Secure Storage) для токенов.
* **Никита:**
  * **AI/ML:** Обертывание API Claude и Whisper в изолированные сервисные классы (`services/ai_service.py`). Написание системных промптов для классификации интентов (намерений) пользователя из текста (например, "хочу встретиться", "покажи расписание").

# Фаза 3: Социальные фичи и WebSockets (Спринт 3)

## Общие задачи (FastAPI):
* Подключение Redis Pub/Sub для синхронизации WS-соединений между несколькими воркерами (Uvicorn).

## Задачи по ролям:
* **Вадим:**
  * **FastAPI:** Разработка REST-эндпоинтов для CRUD расписаний (запись доступных слотов, чтение пересечений).
  * **Next.js:** Разработка календарной сетки, UI выбора слотов доступности, настройка React Query/Zustand для управления стейтом расписания.
* **Алесь:**
  * **FastAPI:** Разработка WebSocket-роутеров (`/ws/status`, `/ws/chat`) для трансляции изменений доступности онлайн-друзьям и создания голосований (Event Proposals).
  * **Flutter:** Интеграция WS-клиента. UI чата и интерактивных карточек голосования за встречу. Мгновенное обновление UI при получении событий.
* **Никита:**
  * **FastAPI / AI:** Создание ML-пайплайна. Реализация сложного эндпоинта: прием текста/аудио -> транскрибация (Whisper) -> парсинг параметров встречи через Claude (кто, когда, где) -> формирование JSON структуры события.

# Фаза 4: Полная интеграция AI и Оркестрация (Спринт 4)

## Задачи по ролям:
* **Вадим (Next.js):**
  * Внедрение Web API (MediaRecorder) для записи аудио через браузер.
  * Разработка UI-состояний AI-помощника (анимации "слушаю", "думаю").
  * Связка фронтенда с эндпоинтом Никиты для отправки аудио-чанков.
* **Алесь (Flutter):**
  * Подключение нативных плагинов для записи звука (управление системными разрешениями на iOS/Android).
  * Реализация плавающих виджетов (FAB) или модальных окон для взаимодействия с AI на мобилке.
* **Никита (AI/ML & FastAPI):**
  * Обработка краевых случаев: настройка Claude на генерацию уточняющих вопросов, если пользователь не назвал точное время или место.
  * Оптимизация UX: реализация стриминга (Streaming Response) текстовых ответов от Claude через WebSockets, чтобы клиенты мгновенно видели текст по мере генерации.
