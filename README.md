# Стек технологий проекта

## Frontend & Mobile Clients

### 📱 Mobile (Основной клиент)
- **Flutter & Dart** — кроссплатформенная мобильная разработка (iOS / Android).
- **Dio** — мощный HTTP-клиент с поддержкой интерцепторов и глобальной конфигурации.
- **web_socket_channel** — нативная работа с WebSockets для real-time чатов и потокового аудио.
- **Drift (SQLite)** — реактивная реляционная локальная БД со строгой типизацией для обеспечения продвинутого офлайн-режима календаря и кэширования данных. (Возможен переход на нереляционную бд)
- **BLoC (flutter_bloc)** — архитектурный паттерн и state management для строгого разделения бизнес-логики и UI, основанный на потоках (Streams).

### 🌐 Web (Маркетинг, Десктоп-версия, Админ-панель)
- **Next.js 14 (App Router)** — React-фреймворк с поддержкой SSR/SSG.
- **React 18** — компонентный UI-слой.
- **TypeScript** — строгая типизация на клиенте.
- **Tailwind CSS** — утилитарный CSS-фреймворк для быстрой верстки.
- **Framer Motion** — библиотека для сложных интерфейсных анимаций.

---

## Backend & Database

- **FastAPI (Python)** — высокопроизводительное ядро API, WebSocket-сервер и интеграционный слой для ИИ-сервисов.
- SQLAlchemy & Alembic —  мощная ORM для работы с базой данных и инструмент для автоматической генерации и управления миграциями.
- **PostgreSQL** — основная реляционная СУБД (хранение пользователей, связей, календаря и чатов).
- (Под вопросом)
    - **OpenAPI Codegen (Type Safety)** — сквозная типизация API вместо tRPC. Автогенерация типов и методов:
        - `openapi-typescript` — для Next.js.
        - `openapi_generator_dio` — для Flutter.

## Artificial Intelligence (AI)
- **Anthropic Claude** — оркестрация расписания, разбор контекста встреч и генерация ответов.
- **Groq Whisper** — сверхбыстрое распознавание голоса (STT) через бинарный WebSocket-стриминг аудио-потока.
*Примечание: ИИ-помощник находится в активной разработке, стек моделей может адаптироваться.*

## Design & Product Management

- **Figma & FigJam** — проектирование интерфейсов (UI/UX), варфреймы и интерактивные прототипы.
- **Notion** — база знаний, ведение технической документации и архитектурных решений (ADR).
- **Miro** — проектирование пользовательских сценариев (User Flows) и ментальных карт (Mind Maps).
- **Adobe Illustrator** — создание векторной графики, иконок и элементов брендинга.
- **Adobe Photoshop** — растровая графика и предпубликационная обработка изображений.
- **Draw.io (Diagrams.net)** — проектирование архитектурных схем, ER-диаграмм базы данных и Sequence-диаграмм для ИИ-сервисов.
